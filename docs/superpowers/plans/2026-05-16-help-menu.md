# Help Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a contextual help modal accessible from all views, with per-screen default section and rich documentation of agent/simulation parameters including MBTI theory.

**Architecture:** A shared composable `useHelp.js` manages open/section state globally. A single `HelpModal.vue` renders the modal with sidebar navigation and scrollable content. Each view adds a `?` button to its header that calls `openHelp(section)`. Help content is structured in `helpContent.js` (pure data, no i18n for now — see note below). Locale strings for UI chrome (button title, close, section labels) go into `locales/*.json` under `help.*`.

**Tech Stack:** Vue 3 Composition API, vue-i18n v11, existing JetBrains Mono / Space Grotesk fonts, no new dependencies.

**i18n note:** Help body text is long-form prose in 3 languages (en, ca, es). Rather than embedding all of it in JSON locale files (which would be unwieldy), the body content lives in per-language JS objects inside `helpContent.js`. The composable selects the right language based on the current i18n locale. UI chrome keys (button title, modal title, section names, "Learn more") are added to the JSON locale files as usual.

## Task 1: Composable `useHelp.js`

**Files:**
- Create: `frontend/src/composables/useHelp.js`

- [ ] **Step 1: Create the composable**

```js
// frontend/src/composables/useHelp.js
import { ref } from 'vue'

const helpOpen = ref(false)
const helpSection = ref('overview')

export function useHelp() {
  function openHelp(section = 'overview') {
    helpSection.value = section
    helpOpen.value = true
  }
  function closeHelp() {
    helpOpen.value = false
  }
  return { helpOpen, helpSection, openHelp, closeHelp }
}
```

- [ ] **Step 2: Commit**

```bash
git add frontend/src/composables/useHelp.js
git commit -m "feat(help): composable useHelp per gestionar estat del modal"
```

## Task 2: Help content data `helpContent.js`

**Files:**
- Create: `frontend/src/data/helpContent.js`

This file exports an object `helpContent` keyed by locale (`en`, `ca`, `es`), each containing an object keyed by section (`overview`, `step1`…`step5`). Each section has `title` (string) and `body` (array of content blocks).

A content block is one of:
- `{ type: 'p', text: '...' }` — paragraph
- `{ type: 'h3', text: '...' }` — subheading
- `{ type: 'table', headers: [...], rows: [[...], ...] }` — table
- `{ type: 'list', items: [...] }` — bullet list
- `{ type: 'learnMore', links: [{ label: '...', url: '...' }] }` — "Learn more" block
